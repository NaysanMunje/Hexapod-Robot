# Model & preview (`hexapod_description`)

Stick kinematics and URDF matching the firmware. **Offline preview:** open [`view_hexapod.html`](view_hexapod.html) (same gait tabs as `/walk`).

| File | Purpose |
|------|---------|
| `view_hexapod.html` | Full robot simulation |
| `view_leg.html` / `view_body.html` | Single leg / chassis |
| `urdf/hexapod.urdf` | Full robot URDF |
| `hips.json` | Hip positions and coxa defaults |
